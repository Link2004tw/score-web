# Score Web

A simple, mobile-first scoreboard web application designed for teachers to record and display student scores. Students will rarely interact with it — this is primarily a quick, no-frills tool for educators.

## Tech Stack

- **Frontend & Backend**: Next.js (App Router)
- **Authentication**: Firebase Auth
- **Database**: Firebase Firestore

## Goals

- Provide teachers with a fast, easy way to add and update student scores
- Display current scores in a clean, mobile-first layout
- Keep it simple — no unnecessary features, just a straightforward score tracker

## Key Principles

- Mobile-first responsive design
- Minimal UI — teachers should be able to add a score in as few taps as possible
- No student-facing complexity — students only view scores
